## FAQ

### What exactly does VideoPatch do?

VideoPatch is a tool that modifies popular video editing software on Windows to remove trial limitations. It unlocks premium features like watermark removal, high-quality exports, and activates plugins and AI tools.

### Is it safe to use VideoPatch?

The application itself is designed to be safe for your system. However, as with any software modification tool, you should download it only from the official repository and be aware that anticomponent programs may flag it due to its patching nature.

### Which versions of the software are supported?

VideoPatch supports the latest and several previous major versions of CapCut, DaVinci Resolve, Filmora, VideoPad, HitFilm, and Movavi. The tool checks for installed versions during the patching process.

### Will this work on macOS or Linux?

No. VideoPatch is a Windows desktop application specifically built for patching software on the Windows operating system. There is no macOS or Linux version.

### Do I need to keep VideoPatch running after activation?

No. VideoPatch applies the patches permanently. Once the process is complete and your software is activated, you can close VideoPatch and continue using the unlocked features normally.

### Is using VideoPatch legal?

VideoPatch modifies software in ways not authorized by its original developers. This may violate the terms of service of those applications. Users are responsible for understanding and complying with the laws and software agreements in their jurisdiction.

### How do I uninstall the patches?

VideoPatch includes a "Restore" feature. Run VideoPatch as administrator, select the patched software, and click "Restore Original" to revert the files to their original state.

### Why is the archive password-protected?

The password "videopatch" is a simple measure to prevent automated scanning and filtering by some network security systems. It is not for encryption of the contents.
